# 🌊 潮汐猎人 Tide Hunter

> 俯视 2D 像素风赶海收集游戏 — MVP 版本

## 🎮 快速启动

**要求：** 电脑已安装 [Node.js](https://nodejs.org)（LTS 版本即可）

| 系统 | 操作 |
|------|------|
| Windows | 双击 `启动游戏.bat` |
| Mac / Linux | 终端运行 `bash 启动游戏.sh` |

浏览器会自动打开 `http://localhost:3000` 进入游戏。

> 如果没有 Node.js，也可以在项目目录运行 `npx serve` 来启动。

## 🕹️ 操作说明

| 按键 | 功能 |
|------|------|
| `W A S D` | 移动 |
| `Shift` | 奔跑（消耗体力） |
| `E` | 采集 / 互动 |
| `Tab` / `B` | 打开背包 |
| `Esc` | 返回村庄 |
| 村庄中 `1-4` | 切换建筑 |
| 村庄中 `空格/回车` | 出海 |
| 背包中 `方向键` | 选择物品 |
| 背包中 `S` | 出售 |
| 背包中 `A` | 水族箱 |
| 背包中 `M` | 博物馆 |

## 🛠 技术栈

- **渲染：** Canvas 2D（像素风 crisp-edges 渲染）
- **语言：** 原生 JavaScript（ES Modules）
- **架构：** 模块化设计，14 个 JS 模块
  - `game.js` — 主循环与场景管理
  - `player.js` — 玩家状态机（待机/步行/奔跑/挖掘/负重）
  - `beach.js` — 海滩地图生成（程序化 tile 铺设）
  - `tide.js` — 潮汐系统（与月相联动）
  - `collectibles.js` — 收集物生成与管理
  - `inventory.js` — 背包系统（容量/负重）
  - `shop.js` — 村庄商店交易
  - `ui.js` — HUD（体力/金币/潮位/月相）
  - `renderer.js` — 渲染管线
  - `sprites.js` / `effects.js` — 精灵动画与特效
  - `data.js` — 游戏数据配置
  - `input.js` — 输入管理
- **素材：** 全部由 AI 生成（即梦 Jimeng），50+ 张像素风 PNG

## 🎯 设计亮点

- **程序化海滩生成：** 基于潮位线的多层 tile 铺设（干沙→湿沙→浅水→中水→深水）
- **潮汐系统：** 实时潮涨潮落，影响可探索区域；与月相周期联动
- **负重机制：** 背包重量 ≥80% 时角色姿态变化，移动速度降低
- **收集物生态：** 蛤蜊（开/闭状态）、海星、海螺、扇贝、沙蟹、古钱币等多种收集物
- **村庄经济：** 出售收集物赚金币，水族箱/博物馆系统
